# 합격 인증

12월 초, 챌린지를 신청할 때만 해도 의욕이 가득했지만, 회사 일에 치여 어느덧 12월 말  
2025년 유종의 미를 걷기 위해 급하게 시험을 접수함  
공부할 수 있는 시간은 단 하루, 12월 27일 시험 당일  
  
**이 글은 절대 추천 방법이 아닙니다**  
그냥 시간이 진짜 없을 때 최후의 수단 같은 방법일 뿐  
일프로님 챌린지 예제풀이가 시험준비의 전부임  
  
## 실제 준비 시간  
시험: 12/27 20:00  
공부: 12/27 11:00 ~ 18:00  
=> 총 7시간  
  
7시간 동안 챌린지 **예제풀이 3회 반복**  
  
## 내 실력 및 경험  
리눅스 기본 명령어 익숙함  
컨테이너는 도커만 써봄  
쿠버네티스 학원 4주 수강 + 어나더 클래스 Sprint 1,2 수강  
완전 쌩초보는 아님  
고수도 아님  
  
## 준비 방법  
챌린지 예제풀이만 팠음  
시험 문제 전부가 예제풀이에서 나옴  
문제 유형, 요구사항, 구조 전부 예제풀이랑 거의 유사함  
문제 안 바뀌면 예제풀이만 제대로 외워도 시험 커버 가능함  
  
## 약간 다른 점  
sysctl 명령어 안 먹힘  
helm install 알 수 없는 에러 발생  
  
## 시험 중 절망편  
왼쪽 패널 오류로 복사 안 됨, Docs 안 열림  
PSI에 문의했지만 해결 안 됨  
재시험 가능했지만 올해 안에 끝내고 싶어서 그냥 진행  
그때부터(16문제 4문제 푼 상태) **모든 명령어, URL, 키워드 수기 입력 시작**  
Docs 직접 찾아가면서 문제 풂  
시간 엄청 잡아먹음  
그래도 예제풀이 3번 푼 경험으로 결국 다 찾을 수 있었음  
  
## killer.sh 관련 조심할 점  
killer.sh는 시험 2시간 30분(150분) 전까지만 활성화됨  
그걸 모르고 시험 2시간 전 접속.. 했을 때 닫혀 있었음  
(물론 URL 찾아서 접속 가능한 방법을 나중에 찾긴 함.. 시험 끝나고 이걸 찾다니..)  
  
# 꿀팁 (합격 빨리 확인하는 법)  
시험 끝나고 접수했던 포탈 다시 접속  
개발자 도구 → Network 탭 켜기  
Take Exam → 이름 입력 칸의 Confirm 클릭  
요청 응답에서 exam_outcome 키 확인  
Pass면 합격  
score도 확인 가능(실제 점수랑 동일한걸로 봐서 확실함)
